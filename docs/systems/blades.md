# Blades in the Dark

*Find the game and its rules at [Blades in the Dark](https://bladesinthedark.com/greetings-scoundrel).*

Blades in the Dark is a rules-light game system where everything comes down to a few d6.

## `/blades`

Roll pools of d6s and highlight the largest number rolled. If you have no dice, instead roll 2d6 and keep the _lowest_. The outcome is shown along with the highlighted die.

* `pool` is the number of dice to roll


<!-- panels:start -->
<!-- panels:title -->
Example:
<!-- div:left-panel -->
```invocation
/blades pool:4
```
<!-- div:right-panel -->
<@user> rolled a rolled **full success** (4d6: [5, 4, 2, **6**])
