/dnd full-attack
* rolls attack sequence based on BAB, where each subsequent attack suffers a cumulative -5 penalty
* a la 1d20+14, 1d20+9, 1d20+4
* modifier must include BAB!
* `swings` determines the number of attacks made as part of the full attack
* `rolls` is the number of full attack sequences to make
* not suitable for monsters that attack with multiple limbs
    - use /dnd attack to handle those manually
* doesn't handle special cases like whirlwind attack or cleave
    - again, use /dnd attack for those
* for no crit, use crit=0
